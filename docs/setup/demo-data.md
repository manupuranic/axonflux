# Demo Database Setup

## Overview

Two databases run side-by-side on the same machine:

| Database | Data | Use |
|---|---|---|
| `axonflux` | Real production data | Daily ops |
| `axonflux_demo` | Synthetic FMCG data | Videos, demos, testing |

Schema is identical — same Alembic migrations, same derived tables, same API. Only the data differs. Switching is one env var.

---

## One-Time Setup (do once per machine)

### 1. Create the database

```powershell
psql -U postgres -c "CREATE DATABASE axonflux_demo;"
```

### 2. Create `.env.demo`

```powershell
Copy-Item .env .env.demo
```

Open `.env.demo` and change one line:
```
dbname=axonflux_demo
```

Everything else (`user`, `password`, `host`, `port`, `SECRET_KEY`) stays the same.

### 3. Create raw + derived schemas

```powershell
psql -U postgres -d axonflux_demo -f sql/raw_tables.sql
psql -U postgres -d axonflux_demo -f sql/derived_tables.sql
```

### 4. Run Alembic migrations

```powershell
$env:dbname = "axonflux_demo"; alembic upgrade head
```

### 5. Seed the calendar dimension

`derived.calendar_dim` (Indian public holidays + retail festivals) is required by the pipeline. Run once — idempotent, safe to repeat.

```powershell
$env:dbname = "axonflux_demo"; $env:PYTHONPATH = "."; python scripts/seed_calendar.py
```

### 6. Install raw dedup triggers

```powershell
$env:dbname = "axonflux_demo"; $env:PYTHONPATH = "."; python scripts/setup_raw_triggers.py
```

### 7. Create admin user

```powershell
$env:dbname = "axonflux_demo"; $env:PYTHONPATH = "."; python scripts/create_admin.py
```

Suggested credentials for the demo: `demo` / `demo123`

### 8. Load demo data (first load)

```powershell
$env:PYTHONPATH = "."; python scripts/demo_reset.py --env .env.demo --yes
```

This generates 6 months of synthetic data and runs the full pipeline. Takes 2–3 minutes.

## Before Each Recording Session

Reset to a clean, known state:

```powershell
$env:PYTHONPATH = "."; python scripts/demo_reset.py --env .env.demo --yes
```

What it does:
1. Truncates all `raw.*` tables and `ingestion_batches`
2. Regenerates synthetic data (`Oct 2025 – Mar 2026`)
3. Copies CSVs → `data/incoming/`
4. Runs `ingest_all.py`
5. Seeds `calendar_dim`
6. Runs full `weekly_pipeline.py`

## Starting the Demo Stack

Two terminals from the project root:

**Terminal 1 — API (pointed at demo DB):**
```powershell
$env:dbname = "axonflux_demo"; $env:PYTHONPATH = "."; python -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2 — Frontend (no change needed):**
```powershell
cd web; npm run dev
```

## Switching Between Production and Demo

No code changes. The frontend always talks to whatever is running on port 8000.

| Want | Start API with |
|---|---|
| Production data | `$env:PYTHONPATH = "."; python -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000` |
| Demo data | `$env:dbname = "axonflux_demo"; $env:PYTHONPATH = "."; python -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000` |

Stop the API, set (or don't set) `$env:dbname`, restart. Frontend at `localhost:3000` reflects the change immediately.

`$env:dbname` is session-scoped — closing the terminal clears it. Opening a new terminal always defaults to production.

## What the Demo Data Includes

Generated by `scripts/generate_demo_data.py` — deterministic (`random.seed(42)`).

- **6 months** of data: Oct 2025 – Mar 2026
- **~623 bills/week**, ~80/day base, 30% uplift on weekends, 60% uplift on festival dates
- **200 named customers** with realistic South Indian names (Usha Pai, Basavaraj Nair…)
- **~29 loyalty members** — inferred via `membercard_discount > 0`
- **60% walk-in rate** across 14 operator-entered name variants (`CASH`, `X`, `MR`, `WALK-IN`…)
- **4 mobile number formats** (+91, 0-prefix, plain 10-digit, garbage) to exercise normalization
- **3 date format variants** (old no-space, new space+12h, new space+24h) to exercise date parsing
- **3 products with duplicate barcodes** (same product entered twice — tests entity resolution)
- **5 products with name typo variants** (tests fuzzy clustering)
- **3 products with zero velocity** (`dead` stock flag)
- **Festival demand spikes** on 7 Indian dates (Dussehra, Diwali, Republic Day…)
